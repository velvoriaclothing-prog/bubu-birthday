# 🎀 BUBU Birthday World — Endless Romantic Memories

A romantic interactive birthday web application dedicated to Bubu, filled with photos, continuous video memories, love letters, mini-games, and surprises.

## ✨ Features
- 🔐 **Passcode Lock Screen**: Enter passcode `1710` to unlock.
- 🎬 **Continuous Ambient Video System**: Endless background video player with playlist advance and audio controls.
- 🌸 **Photo Gallery & Slideshow**: Filter by albums (*Our Moments*, *Sweet Memories*, *Us Together*), ken-burns auto-slideshow, and high-res lightbox.
- 💌 **Love Letters**: Sealed envelopes that open into heartfelt love letters.
- 🎮 **Mini-Games**: Memory Match game & "How Well Do You Know Us?" quiz.
- 🎁 **Mystery Gifts & Schedule**: Interactive mystery gifts and full birthday timeline.
- ⚙️ **Full Photo Management**: Upload new photos and permanently delete photos directly in Settings.
